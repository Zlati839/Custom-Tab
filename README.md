# Custom Tab
A tab with some functions , Music and a OneShot theme :D

## ✨ Features
- Quick Links
  - Gives quick access to certain websites
- Live Clock
   - Live Time output
- Calendar
   - Shows the day, month, and year
- Calculator
- Music Player
  - Play/Pause
  - Progress bar
- Search bar
   - Allows the user to search anything on google
